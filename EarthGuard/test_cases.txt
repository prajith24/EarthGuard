EARTHGUARD v1.0 - TEST CASES AND RESULTS
=========================================

HOW THESE WERE RUN (honest statement)
  - Compiled with:  gcc -std=c11 -Wall -Wextra -pedantic -o earthguard earthguard.c -lm
    GCC 13.3.0 on Ubuntu Linux. Result: no errors, no warnings.
  - The tests below were executed on LINUX by feeding scripted keyboard input
    to the program and reading its output and the files it wrote.
  - The program was also built with AddressSanitizer + UBSan and the full test
    session was replayed: no memory errors, no leaks, no undefined behaviour reported.
  - NOT done: running on Windows, and manual typing in VS Code. The code uses
    only standard C, so the same behaviour is expected on Windows, but this has
    not been verified. Run the tests yourself on Windows and fill in the last
    column (Your result) before submission.
  - "Observed" means what the program actually printed during the run.
